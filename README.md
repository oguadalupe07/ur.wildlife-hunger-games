# UR Wildlife Hunger Games

A lightweight, interactive campus sustainability game for an EcoReps-style classroom presentation.

## Game flow

1. Choose one of four Rochester-area animals: dark-eyed junco, eastern gray squirrel, eastern cottontail, or groundhog.
2. Make a survival choice before the hazard is revealed.
3. Compare how reflective glass, traffic, lawn treatment, and construction affect species differently.
4. Become campus planners with **4 fictional sustainability credits**.
5. See which animals benefit from your plan — and which are left behind.

Main discussion question:

> When we design a “sustainable campus,” whose needs are we actually considering?

## Important note

This is a simplified educational simulation. Game outcomes, credits, and choices are invented for discussion. They are **not** wildlife survival probabilities or measurements of the University of Rochester campus.

## Files

- `index.html` — page structure
- `styles.css` — visual design
- `script.js` — game logic and content

No build step or framework is required.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save.
7. GitHub will show the public Pages URL after deployment.

## Suggested 25–30 minute class flow

- 2–3 min: intro + divide into species teams
- 8–10 min: species mission and choice
- 5 min: compare hazards
- 7–8 min: campus-planner budget
- 3–4 min: debrief

## Suggested discussion prompts

- Why did the same campus affect each species differently?
- Which hazards came from infrastructure versus landscaping?
- Did your planning choices help the species you originally played?
- Is a campus “green” just because it has grass and trees?
- Who gets left out when sustainability decisions focus on only one outcome?
